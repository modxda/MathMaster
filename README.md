# Math Master – Learn & Practice

A beginner-friendly Android maths practice app built with native Java and Android SDK widgets.

## Included features
- Basic calculator (addition, subtraction, multiplication, division)
- Short lessons for the four basic arithmetic operations
- Multiplication tables from 1 to 20
- Common geometry and average formulas
- Random arithmetic quiz with score tracking

## Build an APK
1. Install Android Studio on a computer.
2. Open this folder in Android Studio using **Open**.
3. Allow Gradle sync to complete (Android Studio may download the Android Gradle Plugin and SDK components).
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Find the generated APK under `app/build/outputs/apk/debug/`.

## App details
- App name: Math Master
- Application ID: `com.appgameworld.mathmaster`
- Version: 1.0
- Minimum Android version: Android 6.0 (API 23)

This ZIP contains the Android Studio source project, not a compiled APK. A working APK must be built with Android Studio and the Android SDK, then tested on devices before publishing.
